# N10 — `site/` on Node: task plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the website's scripts run on Node (`node scripts/x.ts`) and are started by pnpm; `@types/bun` and
`setup-bun` leave everything but the release path (`bun run release`, `release.yml`: N11).

**Architecture:** each script keeps its behaviour, only its runtime APIs change: `Bun.Glob` → `fs.globSync`,
`Bun.file`/`Bun.write` → `node:fs`, `Bun.argv` → `process.argv`, `import.meta.dir` → `import.meta.dirname`,
`Bun.serve` + `Bun.gzipSync` → `node:http` + `zlib.gzipSync` with a MIME table (Node has no type lookup).
`serve.ts` exports `serveDist(dist)` so a test can drive it; its CLI runs under `import.meta.main`.

**Tech Stack:** Node 26.13 (type stripping, `fs.globSync`, `import.meta.main`), pnpm 12, Vitest (project `site`).

**Spec:** [`2026-11-12-node-migration.md`](./2026-11-12-node-migration.md), section N10.

## Findings that shape this plan (read on this tree, 2026-11-12)

- `Bun.*` is used by six scripts only: `serve.ts` (serve, file, gzipSync, argv), `postbuild.ts` and
  `check-links.ts` (Glob, file, write), `og.ts` (write), `screenshots.ts` and `demo-seed.ts` (argv). `site/src`
  uses none; `postbuild.ts` imports `../src/lib/site.ts` (no imports, erasable), `screenshots.ts` imports
  `./shots.ts` (type import only), `check-links.ts` imports `./links.ts`.
- `fs.globSync('**/index.html', { cwd: dist })` finds the same 61 pages as `Bun.Glob` (root `index.html` included),
  with no warning.
- `serve.ts` under Bun, measured on a fixture (the behaviour to keep): `/` and `/llama-webui` → 301 `Location:
  /llama-webui/`; `dir` with `dir/index.html` → 301 to `dir/` keeping the query; a file → 200 with Bun's type
  (`text/html;charset=utf-8`, `text/css;charset=utf-8`, `text/javascript;charset=utf-8`,
  `application/json;charset=utf-8`, `text/plain;charset=utf-8`, `application/xml`, `image/svg+xml`, `image/png`,
  `image/webp`, `font/woff2`, else `application/octet-stream`) and `Cache-Control: max-age=600`; text gzipped with
  `Vary: accept-encoding` when accepted, binary never; unknown path or directory without `index.html` → 404 with
  `404.html`; outside `/llama-webui/` (`..` and `%2e%2e` normalized by URL parsing) → 404 `Not found`
  (`text/plain;charset=utf-8`); HEAD → headers only. Bun also sends `content-disposition: filename="…"` on
  non-text files: a Bun quirk GitHub Pages does not have.
- `release.yml` (Bun binaries) and `bun run release` are rewritten by N11: they keep Bun until then.
- Root scripts `site:dev`, `site:build`, `site:preview` call `bun run --cwd site …`; `pnpm check` already uses
  `pnpm --filter llama-webui-site typecheck`.

## Global Constraints

- Behaviour-identical: same `dist/` (pages, sitemap, 404, search index), same links report, same preview server
  answers; `server/contract/golden.json` untouched.
- Biome zero errors / zero warnings; `pnpm lint`, `pnpm check`, `pnpm test`, `pnpm build`, `node scripts/smoke.ts`,
  `pnpm site:build`, `pnpm --dir site check-links`.
- English for code, comments, tests, commits; docs in sync (CLAUDE.md mapping table).
- Ports 7860/7861 belong to the user; manual runs on 7862 (app) and 4175 (preview), `http://192.168.0.20:<port>`.
- Never overwrite committed screenshots or `og.png` with a test capture: write elsewhere or restore them.

## Review Focus

- A path with an encoded character (`sp%20ace.txt`) or a traversal (`%2e%2e`): decoded, or refused outside `dist/`.
- `HEAD` on the preview server: headers, no body (Node does not strip it for us).
- A request the client aborts mid-file: the preview server does not crash.
- `pnpm <script> <args>` passes flags (`--live`, `--port`) through to the script.
- `fs.globSync` and `Bun.Glob` agree on dotfiles and symlinks under `dist/` (none today).

### Task 1: the preview server on `node:http`

**Files:** `site/scripts/serve.ts`, `site/scripts/serve.test.ts` (new).

**Interfaces:** `serveDist(dist: string): Server` (`node:http`, not listening); CLI: `node scripts/serve.ts [--port
4173]` listens on `0.0.0.0` and logs `Serving dist/ like GitHub Pages at http://0.0.0.0:<port>/llama-webui/`.

- [ ] Test first, `serve.test.ts`, on a fixture `dist/` in a temp dir (`index.html`, `docs/deep/index.html`,
      `assets/a.css`, `assets/x.pf_meta` binary, `assets/sp ace.txt`, `sitemap.xml`, `404.html`), server on
      `127.0.0.1:0`, raw `node:http` requests (no automatic decompression):
  - `redirects to the trailing slash like GitHub Pages` — `/`, `/llama-webui` → 301 `/llama-webui/`;
    `/llama-webui/docs?x=1` → 301 `/llama-webui/docs/?x=1`.
  - `serves files with their type and a 10 minute cache` — `/llama-webui/docs/deep/` → 200, `text/html;charset=utf-8`,
    `max-age=600`, the file; `sitemap.xml` → `application/xml`; `x.pf_meta` → `application/octet-stream`;
    `sp%20ace.txt` → `text/plain;charset=utf-8`.
  - `gzips text only, when accepted` — with `accept-encoding: gzip`: `a.css` has `content-encoding: gzip`, `vary:
    accept-encoding` and gunzips to the file; `x.pf_meta` is sent as is.
  - `answers 404.html for an unknown page, Not found outside the base` — `/llama-webui/nope`, `/llama-webui/assets`
    → 404 with `404.html`; `/other`, `/llama-webui/%2e%2e/%2e%2e/etc/passwd` → 404 `Not found`, `text/plain`.
  - `HEAD sends the headers only` — 200, `content-length` of the file, empty body.
- [ ] Run `pnpm exec vitest run site/scripts/serve.test.ts` → Expected: FAIL (`Bun is not defined` or no export).
- [ ] Port `serve.ts`; Run → Expected: PASS. Commit.
