# N7 — Typed RPC client in `web`: task plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** every `api<T>()` call of `web/src` goes through `hc<AppType>` with types inferred from the server's routes,
no cast at a call site, the HTTP contract golden byte-identical, the app still on Bun.

**Architecture:** the server exposes a type-only entry `@llama-webui/server/api` (`server/rpc.ts`) whose declaration
holds the expanded route schema and imports only `hono`, `@llama-webui/shared` and `llamacpp-js/metrics`. The web
app project becomes DOM-only (`types: []`), references `../server`, and a canary proves Node's types stay out; web
tests move to their own project. `web/src/lib/api.ts` keeps `ApiError`/`apiError` and gains `client` and `call()`.

**Tech Stack:** hono 4.13.18 (`hono/client`), TypeScript 7 `tsc -b`, Bun 1.4.4 (runs the app and bundles the web).

**Spec:** [`2026-11-12-node-migration.md`](./2026-11-12-node-migration.md), section N7 (facts 10–12, N0(c)).

## Findings that shape this plan (probe on this tree, 2026-11-12)

- A web project with `types: []` that imports `AppType` from `server/api.ts` sees Node's globals (canary fails):
  `api.d.ts` imports `AppDeps` from `./app` (→ `bun`, `node:*` through every service), and `Env` imports `Server`
  from `bun`. The N0(c) fallback (per-domain types) has the same leak, since each domain imports its repositories.
- The expanded schema in `api.d.ts` (2 208 lines) references only `@llama-webui/shared`, `hono/*` and
  `llamacpp-js/metrics` (no imports). Fix, types only: `Env.Bindings.server` typed structurally
  (`{ timeout(req: Request, seconds: number): void }`), and `server/rpc.ts` exporting a never-called
  `apiSchema = () => createApi(undefined as never)` whose inferred type is emitted in full: `rpc.d.ts` imports
  nothing of the app. With it, the canary compiles and `Profile`, `Settings`, `ConversationDetail`, `ModelList`,
  `Sweep` are assignable from `hc` outputs without a cast.
- The web app project without Bun's types needs two ambient declarations (`web/src/env.d.ts`): `import.meta.hot`
  (`dispose`) and `declare module '*.css'`. Web tests (Vitest on Node) check under `types: ['node']`.
- `hc`: `json` → `JSON.stringify` + `Content-Type: application/json`; no `json` → no body and no content-type;
  query through `URLSearchParams` (server's `searchParams` decodes the same value); `:param` replaced unencoded;
  `init` (e.g. `signal`) spread last; `fetch` injectable (tests).

## Global Constraints

- Golden byte-identical at every commit (`bun test ./server/contract` without `UPDATE_GOLDEN`): server changes in
  this milestone are types and validators that never refuse a request.
- No cast at a call site (`as`, `<T>` on `call`, non-null on a response) to silence a type: fix the type (shared
  type, server output) or narrow an `unknown` with a guard.
- `call()` keeps `api()`'s mapping exactly: body read as text, JSON-parsed when it parses, else the text; empty →
  `undefined`; non-2xx → `apiError(status, body)`; `fetch` rejecting → `ApiError(0, 'llama-webui server unreachable')`.
- Request bodies: a call that sent a JSON body keeps sending the same JSON. A call that sent `'{}'` to a route that
  never reads its body sends none (Ruling in Task 3, the server answers the same: the guard passes a body-less write).
- The web bundle contains no `node:` import; the web app project lists no `types`.
- `pnpm lint`, `pnpm check`, `pnpm test` green at every commit; ports 7860/7861 never used (app smoke on 7862).

## Review Focus

- Query values with `+`, spaces, `#`, `%`, `&`, non-ASCII (model paths, HF search): the server must decode the
  value the old `encodeURIComponent` URL gave.
- A call whose request changed shape (body dropped, content-type added): same answer from the server, including the
  guard (415) and the `Invalid JSON` / `JSON object expected` paths.
- Error mapping: non-JSON error bodies (Bun's own 500 text), 204 and empty 2xx bodies, network failure, abort
  (`signal` on HF search and chat streams) behave as with `api()`.
- Types that changed meaning through `JSONParsed` (optional vs `undefined`, `Date`, records, unions): a call site
  that compiles but reads a field the server never sends.
- Type leakage: anything that makes `@types/node` or `bun-types` visible to the web app project again (a server
  output type defined in a module that imports `node:*`).
