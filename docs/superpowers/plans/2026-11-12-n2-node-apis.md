# N2 — Runtime-neutral `node:*` replacements: task plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** every `Bun.spawn`/`file`/`sleep`/`which`/`CryptoHasher`/`argv`/`write`, `import.meta.dir` and `Timer` in the
app, its tests, `scripts/release.ts`, `scripts/smoke-binary.ts` and `testdata/fake/` goes through `node:*`; the
remaining Bun-only access is fenced so that server modules load on Node. Bun still runs everything.

**Architecture:** one module, `server/proc.ts`, mirrors the Bun subset in use (`Spawned` with web streams and
`exited`), so call sites barely change. Tests write files through `server/testing/write.ts` (creates parent
directories, as `Bun.write` does). The fakes become plain Node scripts (`node:http`, erasable TS).

**Tech Stack:** Bun 1.4.4 (runtime), Node 26.13.0 (fakes, llamacpp-js tests), TypeScript 7.0.2.

**Spec:** [`2026-11-12-node-migration.md`](./2026-11-12-node-migration.md), section N2.

## Global Constraints

- Behaviour-identical port: same HTTP contract, same log lines, same states; no refactoring (candidates → notes).
- Out of scope, stays Bun until N6/N8/N11: `Bun.serve` (`server/app.ts`, `server/routes/routes.test.ts`),
  `Bun.build`/HTML import (`server/routes/web.ts`, its test, `scripts/compile.ts`, llamacpp-js `package.test.ts`),
  `bun:sqlite`, `bun:ffi`, `Bun.main`/`Bun.pathToFileURL` inside the standalone branch of `workerUrl()`.
- `server/standalone.ts`: `export const isStandalone = typeof Bun !== 'undefined' && Bun.isStandaloneExecutable`
  (removed in N8); `cli.ts`, `index.ts`, `nvml/monitor.ts` read it instead of `Bun.isStandaloneExecutable`.
- Fakes: erasable TS, `.ts` import extensions, run by `node` (wrappers `exec node`), no `BUN_PATH`.
- Biome clean, `bun run check` clean, gate below green at every commit.

## Review Focus

- Spawn failure (missing binary, non-executable file, missing `cwd`): Bun throws synchronously, Node emits `'error'`
  later with `pid === undefined`. `spawnProc` must throw synchronously with a message naming the binary and the real
  cause (`spawn <bin> ENOENT` / `EACCES`), and swallow the later `'error'` event (no unhandled error, no crash).
- `exited` resolves on `'exit'` while stdout/stderr may still hold data: the supervisor's "exited" log line and the
  bench's final output read must keep their order (supervisor and bench tests are the oracle).
- `exitCode`/`signalCode` must be set when `exited` resolves (SIGTERM → `exitCode` null, `signalCode` `'SIGTERM'`).
- `kill()` after exit must not throw.
- `Bun.file().exists()` is false for a directory: `fileExists` keeps that (a model path that is a directory is still
  "Model not found").

### Task 1: `server/proc.ts`

**Files:** Create `server/proc.ts`, `server/proc.test.ts`.

**Interfaces — Produces:**

```ts
export interface Spawned { pid: number; stdout: ReadableStream<Uint8Array> | null; stderr: ReadableStream<Uint8Array> | null;
  exited: Promise<number | null>; readonly exitCode: number | null; readonly signalCode: NodeJS.Signals | null;
  kill(signal?: NodeJS.Signals): void }
export interface SpawnOptions { cwd?: string; env?: Record<string, string | undefined>; stdin?: 'ignore';
  stdout?: 'pipe' | 'ignore'; stderr?: 'pipe' | 'ignore'; timeout?: number; killSignal?: NodeJS.Signals }
export type Spawn = (argv: string[], o?: SpawnOptions) => Spawned;
export const spawnProc: Spawn;
export function readText(path: string): Promise<string>;          // readFile utf8
export function fileExists(path: string): Promise<boolean>;      // stat().isFile(), false on error
export function fileRange(path: string, start: number, end: number): ReadableStream<Uint8Array>; // [start, end)
export function which(bin: string): string | null;               // PATH scan, X_OK, sync like Bun.which
```

- [ ] **Step 1:** tests (bun:test): `spawnProc(['sh','-c','echo out; echo err >&2; exit 3'])` → stdout/stderr text via
      `new Response(...)`, `await exited` then `exitCode` 3, `signalCode` null; `sh -c 'kill -TERM $$'` → `exitCode`
      null, `signalCode` `'SIGTERM'`; `['sleep','5']` with `timeout: 100, killSignal: 'SIGKILL'` → `signalCode`
      `'SIGKILL'` in < 2 s; missing binary throws synchronously `/spawn \/nope\/x ENOENT/` and no `'error'` escapes;
      a non-executable file throws `/EACCES/`; missing `cwd` throws `/ENOENT/`; `kill()` after exit does not throw;
      `stdout: 'ignore'` → `stdout` null; `which('sh')` is an absolute path, `which('no-such-bin-xyz')` null,
      `which('/bin/sh')` returns it; `fileRange` of a 10-byte file `[2, 5)` → 3 bytes; `fileExists` false for a
      directory and a missing path, true for a file.
