# Topology in 2D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the three.js scene of the Topology page with an animated 2D drawing in two views, Cards and Board, switched by a control on the page, with a detail panel per block.

**Architecture:** Pure modules compute everything worth testing: the tree of the hardware graph, the geometry of a link, the placement of each view, what a streak lane shows. Thin React components put HTML blocks at the rectangles of a layout, over one SVG for the tracks and one canvas for the streaks, drawn by a 20 fps timer that stops when nothing flows. `flows.ts` stays the projection of the snapshot onto the graph.

**Tech Stack:** React 19, Tailwind 4 (tokens of `@llama-webui/theme`), SVG, canvas 2D, Vitest in Node without a DOM. No new dependency; `three`, `@react-three/fiber`, `@react-three/drei` and `@types/three` leave.

**Spec:** `docs/superpowers/specs/2026-11-23-topology-2d-design.md`. The mockup it refers to is `.cache/spikes/topology-2d/index.html` (untracked): its sizes and its streak parameters are the starting point.

## Global Constraints

- Nothing under `app/server/` or `packages/webui-shared/` changes: no new measurement, no API change.
- Tests run in Node without a DOM: placement, geometry, lanes, detail rows and the stored view are pure functions.
- No script per frame for the drawing: values change once per sample (1 Hz) and ease by CSS transitions in `steps()`; the only timer is the streaks', at 20 fps, stopped and its canvas cleared when no link is shown, never started under reduced motion.
- A state is never carried by color alone: a level is spelled out in text; every figure is reachable by click, Enter or Space.
- Both views read the same `nodeLive`, `linkFlows`, `linkBadge`, `peerLinks`: same values, levels and wording; one detail panel.
- Thresholds are the existing ones: `FILL_WARN_PCT` 85, `FILL_CRIT_PCT` 95, `LINK_WARN` 0.7, `LINK_CRIT` 0.9, `FLOOR_BPS` 1e5, `REST_FLOOR_BPS` 8 MiB/s, log scale up to 20e9.
- Streaks: 1 to 8 per lane, at most `round(length / 26)` (never fewer than 2 slots), speed `45 + 190 × x` px/s, length 12 px.
- Scale of the drawing in its frame: between 0.75 and 1.5; under 0.75 it scrolls.
- UI text in English; numbers and units through `app/src/lib/format.ts`.
- React lint rules of the project: no state mirrored in an effect, `useEffectEvent` rather than a suppression, no `react-hooks/…` directive.
- Before each commit: `pnpm lint`, `pnpm check`, `pnpm test` green. Documentation in the same PR.

## Review Focus

1. **A graph the convention has no place for** (an unlinked block, a GPU with no bus address, no memory block, no CPU): every block stays visible and no placement throws. Test in Task 3 (`loose` blocks, graphs without `ram` or `cpu`).
2. **A machine larger than the mockup's** (four GPUs on the CPU plus two behind a chipset, eight DIMMs, 32 threads): no overlap, no crossing on the board, a drawing that grows instead of squeezing. Test in Task 3.
3. **A link shorter than a streak** (a drive next to the socket): no division by zero, no streak drawn outside its track. Test in Task 4 (`makeLane` on a 10 px route).
4. **A selected block that leaves the graph** (the graph is read again on a reconnect): the detail closes instead of showing stale figures. Test in Task 2 (`detailOf` returns null for an unknown id).
5. **Storage that throws or holds an old value** (private window, a value from another version): the page opens on Cards. Test in Task 5.

### Task 1: Geometry

**Files:** Create `app/src/features/topology/geometry.ts`, `geometry.test.ts`.

**Interfaces (produces):**

```ts
export interface Point { x: number; y: number }
export interface Rect { x: number; y: number; w: number; h: number }
/** A link as drawn: its SVG path, and points evenly spaced along it (first on the start, last on the end). */
export interface Route { d: string; points: readonly Point[]; length: number }
export function straight(a: Point, b: Point): Route;
export function curve(a: Point, c1: Point, c2: Point, b: Point): Route; // cubic Bézier
export function elbow(corners: readonly Point[], radius?: number): Route; // right angles, rounded (default 10)
export function reversed(route: Route): Route;
export function overlaps(a: Rect, b: Rect, gap?: number): boolean;
export function inside(p: Point, r: Rect): boolean;
export function crosses(a: Route, b: Route): boolean; // their polylines intersect
export function onEdge(p: Point, r: Rect, tolerance?: number): boolean;
export function fitScale(frame: { w: number; h: number }, natural: { w: number; h: number }): number;
export const SCALE_MIN = 0.75; export const SCALE_MAX = 1.5;
```

Points are spaced about 9 px apart, at least 6 intervals, from a fine flattening of the path (the browser's `getTotalLength` is not available in tests).

  cpu: TopologyNode | null;
  ram: TopologyNode | null;
  /** GPUs on an `internal` link of the CPU: part of it, not a device in a slot. */
  integrated: TopologyNode[];

export interface BoardLayout extends ViewLayout {

Rules the tests do not determine:

- A route goes from the link's `from` to its `to`. Badge anchors: every `pcie` and `memory` link has one, an `internal` link has none.
- **Cards** (mockup's `buildCards`): CPU 300 × 150 (176 with more than 16 threads), memory and integrated GPUs 250 × 124 at its left and right, a GPU card 216 to 290 wide × 170, NVMe 210 × 96, chipset 230 × 96, 26 px between cards, 96 px between rows, margins 30. Rows are as wide as they need: the drawing's width is the widest row's, never less than the first row's. Each chipset's devices are one row further, centered under it, shifted right when two groups would collide. A link drops from the bottom of its parent and crosses 40 px above its card; its badge sits in the gap beside the arrival. Loose blocks end the first device row.
- **Board** (mockup's `buildBoard`, without its fixed 1,120 px): socket 180 × 180; the memory's rectangle at its right holds the label and the DIMM slots (four slots, a module in two of them unless `detail.dimms` says otherwise; more than four modules: as many slots, narrower); one slot of 558 × 84 per GPU every 112 px, the CPU's first then the chipsets'; chipsets 100 × 100 at the lower right, stacked, each with its drives under it; the CPU's drives then the integrated GPUs as sticks of 190 × 32 at the socket's left, every 56 px; loose blocks as slots after the last. The badge of a slot sits at its left end, outside it; a stick's badge at its left. The socket and the board grow with what hangs off them: tracks of the CPU's slots leave the socket's bottom edge each in its own channel (a port further right turns higher and runs further right), so no two cross.
- Peer links: between the two cards' facing sides (cards) or along the slots' left part (board); their tag at the middle.

### Task 4: Streaks

**Interfaces (produces):**

```ts
export const STREAK_FPS = 20;
export const STREAK_LENGTH = 12;
/** Place of a throughput on the log scale from FLOOR_BPS to CEIL_BPS (0..1); null under the floor or unmeasured. */
export function intensity(bps: number | null): number | null;
export const speedOf = (x: number) => 45 + 190 * x; // px/s
export interface Lane { points: readonly Point[]; length: number; /** Streak slots, and the order they fill in. */ max: number; rank: readonly number[] }
/** One direction of a link: the route (already in travel direction) shifted `side` px to its right. */
export function makeLane(route: Route, side: number): Lane;
export interface Streak { tail: Point; head: Point; alpha: number }
/** The streaks of a lane at progress `t` (0..1 of a traverse) for an intensity `x`. */
export function streaksAt(lane: Lane, x: number, t: number): Streak[];
export interface LaneState { fwd: number | null; back: number | null; level: Level }
/** Links with streaks to draw, by id: none under reduced motion, none for a link `linkShown` holds back. */
export function laneStates(links: readonly TopologyLink[], flows: Map<string, LinkFlow>, busy: boolean, reducedMotion: boolean): Map<string, LaneState>;
/** Intensity of a link's track (0..1): its busier direction's when shown, CPU activity for an unmeasured memory link. */
export function trackIntensity(link: TopologyLink, flow: LinkFlow | undefined, busy: boolean): number | null;
export interface StreakLoop { setLinks(links: readonly LinkGeo[]): void; setStates(states: Map<string, LaneState>, colorOf: (id: string, level: Level) => string): void; resize(width: number, height: number, ratio: number): void; stop(): void; readonly running: boolean }
export function createStreakLoop(canvas: HTMLCanvasElement): StreakLoop;
```
