# oxc migration, L1: oxfmt replaces Biome's formatter

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** oxfmt formats the code of the repository (TS, TSX, JS, JSON, CSS, YAML) and orders imports and `package.json`;
Biome only lints.

**Architecture:** One `oxfmt.config.ts` at the root. `biome.jsonc` keeps its linter and loses its formatter and its
`assist` block. `pnpm lint` runs both tools until L3 removes Biome.

**Tech Stack:** oxfmt 0.79.0 (exact), Biome 2.6.8 (lint only), pnpm.

**Spec:** `docs/superpowers/specs/2026-11-22-oxc-migration-design.md` (sections "Formatter", "Milestones" row L1) and
its appendix `2026-11-22-oxc-migration-measurements.md` §4.

## Global Constraints

- Branch `chore/oxfmt` from `master`; one PR; green on `pnpm lint`, `pnpm check` (`pnpm check 2>&1 | grep -c 'effect('`
  gives 0) and `pnpm test`.
- Style unchanged: 2 spaces, single quotes (double in JSX), 120 columns, semicolons, trailing commas, `quoteProps`
  as needed.
- No sort other than imports and `package.json` keys. No Tailwind class sort yet (L6).
- Never formatted: `repos/`, `**/src/components/ui`, `app/server/contract/golden.json`, `**/testdata`,
  `pnpm-lock.yaml`, `docs/`, every `.md` and `.mdx` (L2 opens `site/content/**/*.mdx` and `README.md`), `.claude`,
  `.agents`, and what `.gitignore` lists (oxfmt reads `.gitignore` by itself: checked in the spike).
- `repos/` is never edited. No `npx`: `pnpm exec`, `pnpm dlx`.
- Commits and PR in English; commit messages end with `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.

## Review Focus

- A file type Biome never formatted gets rewritten (HTML, TOML, a `.json` fixture): expected, only the scope above
  changes. Task 2 lists what oxfmt touched by extension and ignores anything outside the scope.
- A generated or compared file is reformatted and a test compares it byte for byte (`golden.json`, fixtures under
  `testdata`, the `.sqlite` fixtures' neighbours): expected, `pnpm test` stays green with no golden update.
- CSS and YAML strings switch to single quotes: expected, they keep their double quotes (the override of Task 1).
- A `biome-ignore` comment ends up one line away from the node it covered after the reformat: expected,
  `biome lint` reports no new error and no unused suppression (Task 3).

### Task 1: The config and the scripts

**Files:**
- Create: `oxfmt.config.ts`
- Modify: `package.json` (devDependency, scripts), `pnpm-lock.yaml`, `biome.jsonc`

- [ ] **Step 1:** `pnpm add -D -w -E oxfmt@0.79.0`. Keep any `minimumReleaseAgeExclude` entry pnpm adds to
  `pnpm-workspace.yaml`.
- [ ] **Step 2:** Write `oxfmt.config.ts` (`import { defineConfig } from 'oxfmt'`, default export) with exactly:
  `printWidth: 120`, `singleQuote: true`, `sortImports: { newlinesBetween: false }`, `sortPackageJson: true`,
  `overrides: [{ files: ['**/*.css', '**/*.yaml', '**/*.yml'], options: { singleQuote: false } }]`, and
  `ignorePatterns` for the "never formatted" list above that `.gitignore` does not already cover. A one-line comment
  per entry that is not self-evident (why `golden.json`, why `components/ui`), copied from `biome.jsonc`.
- [ ] **Step 3:** `biome.jsonc`: `formatter.enabled: false`, remove the `assist` block and the `javascript.formatter`
  block. Leave the linter untouched.
- [ ] **Step 4:** Root scripts: `"format": "oxfmt"`, `"lint": "oxfmt --check && biome lint"`,
  `"lint:fix": "biome lint --write && oxfmt"`.
- [ ] **Step 5:** Run `pnpm exec oxfmt --check`. Expected: it runs, lists the files it would change, exits 1.
  Run `pnpm exec biome lint`. Expected: exit 0.
- [ ] **Step 6:** Commit: `chore: add oxfmt and its config`.
