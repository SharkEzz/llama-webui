# oxc migration, L2: oxfmt formats the MDX of the site and the README

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `site/content/**/*.mdx` and `README.md` are formatted by oxfmt, with the rendered site unchanged.

**Architecture:** Two content fixes first (they are what makes the formatter safe), then the scope of
`oxfmt.config.ts` widens, then the raw output. The proof is a comparison of the prerendered HTML before and after.

**Tech Stack:** oxfmt 0.79.0, React Router prerender (`pnpm site:build`), `pnpm --dir site check-links`.

**Spec:** `docs/superpowers/specs/2026-11-22-oxc-migration-design.md` (row L2) and appendix §4.

## Global Constraints

- Starts once the L1 PR is merged. Branch `chore/oxfmt-mdx` from `master`; one PR; green on `pnpm lint`,
  `pnpm check`, `pnpm test`.
- Fenced code blocks in MDX stay as written: `embeddedLanguageFormatting: 'off'` for `**/*.mdx`.
- `docs/` and every `.md` other than `README.md` stay unformatted.
- No change of what a page says or shows.

## Review Focus

- A component whose children are Markdown glued to its tags (`<FileTree>`, `<Steps>`, `<Tabs>`, `<Callout>`) turns
  into a paragraph: expected, the HTML comparison of Task 3 shows no page with a different element structure.
- A table cell with a pipe inside inline code is realigned and split: expected, same cells before and after.
- A front matter value requoted: expected, `title` and `description` read the same (the build fails otherwise).
- A link or an anchor changed by a reformatted heading: expected, `check-links` passes.

### Task 1: The reference build

- [ ] **Step 1:** On the untouched branch: `pnpm site:build`, copy `site/dist` to a directory outside the repository
  (the session scratchpad), as `dist-before`.
- [ ] **Step 2:** Write, in the scratchpad (not committed), a script that takes two `dist` directories and, for every
  `.html`, compares the pages after collapsing runs of whitespace; it prints the pages that differ and, for each,
  whether the difference is only inside `<pre>` elements. Hashed asset names differ between two builds: replace
  `/assets/<name>-<hash>.<ext>` by `/assets/<name>.<ext>` before comparing.
- [ ] **Step 3:** Run it on `dist-before` against a second fresh build of the same tree. Expected: 0 page differs
  (otherwise the script, not the content, is at fault: fix it first).

### Task 2: Content fixes

  `site/content/developers/contributing/testing.mdx`, `site/content/developers/api/bench.mdx:46`

- [ ] **Step 1:** In the three pages, put a blank line after every `<FileTree>` opening tag and before every
  `</FileTree>`. Search the other pages for the same shape (a block component whose first child line follows the tag
  without a blank line: `grep -n -A1 '^<\(FileTree\|Steps\|Step\|Tabs\|Tab\|Callout\)' site/content -r`) and give them
  the blank lines only if Task 3 shows them breaking.
- [ ] **Step 2:** `bench.mdx:46`: a table row is glued to the paragraph above it. Read the page, restore what was
  meant (the row back in its table, or the paragraph separated by a blank line).
- [ ] **Step 3:** `pnpm site:build`; compare with `dist-before`. Expected: only `api/bench` differs, and it now renders
  the table correctly. Keep this build as the new `dist-before`.
- [ ] **Step 4:** Commit: `docs(site): blank lines inside FileTree, a stray table row`.

### Task 3: Scope and raw output

**Files:**
- Modify: `oxfmt.config.ts`; rewritten by the formatter: `site/content/**/*.mdx`, possibly `README.md`
- Create: `.git-blame-ignore-revs`

- [ ] **Step 1:** `oxfmt.config.ts`: stop ignoring `site/content/**/*.mdx` and `README.md` (every other `.md`, and any
  `.mdx` elsewhere, stays ignored); add the override `{ files: ['**/*.mdx'], options: { embeddedLanguageFormatting: 'off' } }`.
- [ ] **Step 2:** `pnpm format`. Expected: about 32 files change, all under `site/content/developers` (tables);
  `README.md` and `site/content/docs` unchanged or nearly.
- [ ] **Step 3:** `pnpm site:build`, compare with `dist-before`. Expected: no page differs after whitespace collapse.
  A page that differs: read its diff; a broken component gets its blank lines (amend Task 2's kind of fix in a commit
  placed before the raw output), a change inside `<pre>` means the override of Step 1 is not applied.
- [ ] **Step 4:** `pnpm --dir site check-links`. Expected: every link and anchor resolves.
- [ ] **Step 5:** Commit the config (`chore: oxfmt formats the site's MDX and the README`), then the formatter's
  output alone (`style(site): format the MDX with oxfmt`).
- [ ] **Step 6:** Create `.git-blame-ignore-revs` with the squash commit of the L1 PR on `master`
  (`git log --oneline master | grep -i 'oxfmt'`), one comment line above it naming the PR. Commit:
  `chore: ignore the oxfmt reformat in git blame`.
