# N11 — Package and release: task plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a release is an npm tarball of the root package (`npm install -g ./llama-webui-<version>.tgz` gives a
`llama-webui` command), built, smoke-tested from an empty install and published by `release.yml` on Node; Bun leaves
the repository's tooling.

**Architecture:** the root `package.json` is the packed one (`bin`, `files`, `os`); `dist/server/main.js` already
starts with `#!/usr/bin/env node` and imports only Node, `hono`, `@hono/node-server` and `ws`, the root's only
`dependencies`. `scripts/smoke.ts --tarball` packs (or takes) the tarball, installs it with npm in an empty prefix and
runs the N8 checks through `node_modules/.bin/llama-webui`.

**Tech Stack:** Node 26.13, pnpm 12.19 (`pnpm pack` rewrites `catalog:`), npm 11 (the user's installer).

**Spec:** [`2026-11-12-node-migration.md`](./2026-11-12-node-migration.md), section N11; spike N0 (bundle shape).

## Findings that shape this plan (read on this tree, 2026-11-12)

- Spike: with `bin`, `files` and `os` added, `pnpm pack` works with `private: true` and rewrites `catalog:` to
  ranges; the tarball is 1.5 MB (`dist/server/{main.js,nvml-worker.js,THIRD-PARTY-LICENSES.md}`, `dist/web/**`,
  `LICENSE`, `README.md`, `package.json`); `npm install --prefix <empty> ./llama-webui-0.2.1.tgz` adds 4 packages
  (9.2 MiB) in 1 s, and `.bin/llama-webui --help` runs.
- `dist/` also holds `dist/llama-webui`, a 115 MB executable left by the old `bun run compile` (git-ignored):
  `files: ["dist"]` would ship it. `files` lists `dist/server` and `dist/web`.
- The root's `dependencies` are already exactly `hono`, `@hono/node-server`, `ws` (`catalog:`); the bundled
  libraries and the workspace packages are dependencies of `server/` and `web/`, which the build resolves: the root
  needs no `devDependencies` for them.
- `--help` shows `pnpm dev` / `pnpm start` only: wrong for an installed `llama-webui`.
- `release.yml` still compiles Bun binaries with `bun run compile` (removed in N8) and `scripts/smoke-binary.ts` (gone):
  it is broken today. `bun run release` / `bun scripts/release.ts` are the last Bun commands of the tooling.

## Global Constraints

- Behaviour-identical app; `server/contract/golden.json` untouched.
- Biome zero errors / zero warnings; `pnpm lint`, `pnpm check`, `pnpm test`, `pnpm build`, `node scripts/smoke.ts`,
  and from this milestone `node scripts/smoke.ts --tarball`.
- English for code, comments, tests, commits; docs in sync (CLAUDE.md mapping table).
- Ports 7860/7861 belong to the user; manual runs on 7862, `http://192.168.0.20:7862`.
- Nothing is installed into the user's own global prefix: global installs go to a prefix in the scratchpad.

## Review Focus

- An install where npm cannot resolve a runtime import: `main.js` or `nvml-worker.js` importing a bundled library
  left external — the tarball smoke starts from an empty prefix, so it fails there.
- The bin run as a symlink (`.bin/llama-webui` → `dist/server/main.js`): `dist/web` and `nvml-worker.js` are found
  next to the real file, not next to the link.
- A tag whose version differs from the package.json files: the workflow stops before building.
- A release tarball built from a dirty tree: the version reported by `/api/health` is the tag, not `-dirty`.
- `pnpm pack` with no build: the tarball must not ship without `dist/`.

### Task 2: the tarball smoke

**Files:** `scripts/smoke.ts`, `.github/workflows/ci.yml`.

**Interface:** `node scripts/smoke.ts [dist/server/main.js]` (unchanged); `node scripts/smoke.ts --tarball
[file.tgz]`: without a file, `pnpm pack` into a temp dir (fails when `dist/server/main.js` is missing); then `npm
install --prefix <tmp> <tgz>` and the same checks through `<tmp>/node_modules/.bin/llama-webui` (run directly: shebang
and exec bit), the temp dirs removed at the end.

- [ ] Run `node scripts/smoke.ts --tarball` before the change → Expected: FAIL (`--tarball` read as the main path).
- [ ] Implement; Run → Expected: `smoke: ok (…/node_modules/.bin/llama-webui v…, …)`. Mutation check: drop `ws` from
      the root `dependencies` (pack only) → Expected: the tarball smoke fails; restore.
- [ ] `ci.yml`: `node scripts/smoke.ts --tarball` after the build smoke. Commit.
